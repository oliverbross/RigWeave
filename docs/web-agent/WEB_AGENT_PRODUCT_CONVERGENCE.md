# Web and Station Agent product convergence

This branch starts at exact M8 Agent SHA `96a4bfca41a6b2d899d86ff38a88ab5e45071d4c`. The already-accepted desktop Flightline, functional ownership and M8 relay implementation are retained. New package lifecycle controls make the same compiled Agent operable on Windows, macOS and Linux without moving hardware authority into Web or Node.

M9 mobile branches are preserved and unmerged. No Android/iOS production source is changed. Candidates are unsigned and private; live hardware, audio, CAT/PTT/TUNE/TX/RF, rotator, provider and public-release acceptance remain separate.
