# M9 live acceptance boundaries

Local automated acceptance covers compilation, migration, crypto interoperability, simulator/emulator surfaces, finite scale, and package checks. No protected Lenovo install/change, native app-data mutation, live radio/RF/CAT/PTT/TUNE/TX/rotator action, TestFlight/upload/signing, production Hosted deployment, or long soak is part of M9. Those remain distinct later acceptance gates.
