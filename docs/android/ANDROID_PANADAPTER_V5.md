# Android Panadapter v5

The existing Panadapter owner remains authoritative. v5 adds direct digit entry, bounded digit stepping, explicit QSY review, touch/zoom/pan inspection, dual-receiver presentation, time-shift review, bookmarks, and skimmer markers.

Paused or replaying time-shift state draws the selected reduced trace and labels it as time shift. The live waterfall remains visually distinct. Marker taps open an inspector; tuning occurs only through the explicit Receive Review action. Opening Digi navigates without tuning or transmitting.
