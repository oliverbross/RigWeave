# Desktop Functional Parity Closure v1

Branch: `feature/desktop-functional-parity-closure-v1`

Immutable UI/source baseline: `de32c8ac908c7979f39bfdfc41ca050378901e75`.

## Contract

This programme replaces the 17 `FOUNDATION_WIRED` rows with production desktop owners while preserving the accepted Deep Convergence v2 layouts, native menus, command registry, sidebar, Edit Layout policy, design tokens, accessibility/focus model, responsive breakpoints and deterministic gallery profiles.

Source completion requires an owner, domain behavior, storage/migration where applicable, protocol/provider client, safe lifecycle, QML action binding, loading/empty/error truth, configuration/recovery, health/privacy, tests and package inclusion. Physical radio/audio/CAT/PTT/TUNE/RF, rotator movement, authenticated-provider, signing and release acceptance remain separate evidence.

## Safety baseline

- Restore is disconnected, RX-only and disarmed.
- Radio profile selection never connects.
- Transmit and rotator movement acceptance default false after create, migration and import.
- External spots/news/evidence never create Digi or Chaser eligibility.
- N1MM defaults disabled, loopback, untrusted, unarmed and non-restoring.
- N1MM contact/replace/delete, lookup, radio, spot, talk and score packets are field-whitelisted, deduplicated and review-only; paired framing is bounded and inbound packets never operate radio, Keyer, Digi or Chaser.
- SCP is fetched only at runtime from the official HTTPS endpoint (or an explicit loopback test endpoint), validated into SQLite, atomically promoted over the last-good generation and reported with source, date, digest and row count.
- Global Stop cancels provider work and disarms every operating workflow; physical RX/stop is claimed only after readback.
- Credentials stay in Windows Credential Manager/macOS Keychain aliases and never enter databases, configuration exports, diagnostics or support bundles.

The baseline already has one canonical QSO owner, Wavelog sync owner, cluster/spot owner, generic Hamlib/TCI radio owner, Hamlib rotator owner, Panadapter owner, provider/cache policy, five versioned domain stores, accepted QML layouts, deterministic galleries and exact-SHA multi-platform CI.
