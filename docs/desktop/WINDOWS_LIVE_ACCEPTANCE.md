# Windows live acceptance

Automated source/build evidence is not physical or authenticated acceptance. The following remain pending on a representative Windows 10/11 x64 machine:

1. keyboard, pointer, high-DPI, 1280×720/1920×1080, screen reader and large-font visual review;
2. install, launch, Start Menu, optional shortcut policy, upgrade, uninstall and user-data preservation;
3. Windows Credential Manager write/update/read/delete without secret disclosure;
4. authenticated Wavelog capability/station discovery, Initial/Quick/Full sync, conflicts, tombstones and ambiguous-write recovery;
5. live cluster login/TLS/SH-DX/reconnect with bounded input;
6. physical Hamlib radio connect/read/control only; PTT/TUNE remain disabled and no RF test is required;
7. physical Hamlib rotator telemetry and explicit PROMPT movement, with STOP confirmation; no PTT coexistence test;
8. exact stereo I/Q input, unplug/replug refusal, 48/96 kHz performance and QMX/QMX+ UAC correlation;
9. support ZIP manual privacy inspection; and
10. process working-set measurements for idle, 100k Logbook, 20k Band Map and live Panadapter.

No Android tablet, iOS device, radio, rotator or audio hardware is touched by this branch programme.
