# Desktop Visual Rubric v2

Each dimension is scored 0–3: hierarchy, reachability, tablet identity,
desktop adaptation, density, alignment, typography, colour/status,
responsive/high-DPI, and empty/loading/error/safety states. A core workspace
passes at 25/30 with no zero, clipped primary action, fabricated state, or
critical reachability defect.

The before scores describe accepted v1 at `9c0e3d6`. After scores describe
the deterministic macOS v2 gallery; Windows visual confirmation remains
pending and does not inherit these scores.
