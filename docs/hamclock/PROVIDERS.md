## Coalescing contract

`HamClockInFlightCoalescer` is shared by the native Home public-provider group. One active request/result exists per exact key, distinct keys may execute independently, an interrupted observer does not cancel the shared future, exceptional completion removes the key, and completed results are not retained. Provider TTL and last-good disk caches remain authoritative.

## Manual refresh boundary

Home exposes one operator SYNC action for the existing Neural DX, solar and portable controller lifecycle. Contest, DXpedition and celestial providers refresh automatically; they do not present misleading per-provider manual controls. No provider request can tune, transmit, key PTT, update runtime source code, or mutate an upstream pin.
